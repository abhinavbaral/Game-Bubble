 Game Bubble

A simple web-based bubble brust game that brings back the nostalgia of classic games. R 

About

Game BUBBLE is a lightweight browser game inspired by the bubble blast. It focuses on simplicity, smooth gameplay, and a retro feel.

Features
* Easy controls
* Play directly in your browser
* No installation required

Getting Started

1. Clone the repository
2. Open the project folder
3. Launch `index.html` in your browser

Controls

* Use your mouse to hit the target number.
* The number keep on changing so stay focused.
